## 👋 About me

I’m **Nazar Kuzenko**, a **Senior / Lead Mobile Developer** focused on building practical, polished, and scalable mobile products.

My main stack is **Flutter, Dart, Kotlin, Java, Firebase, REST APIs, subscriptions, analytics, AI integrations, App Store Connect, and Google Play Console**.

I build apps from idea to production: product structure, mobile architecture, clean UI, backend integration, analytics, monetization, release preparation, store optimization, and post-release iteration.

Currently building **Sych-Tech** — an independent mobile app studio focused on AI-powered consumer apps, mobile-first products, and practical AI workflows.

---

## 🚀 What I build

* Production-ready Flutter mobile apps
* Native Android apps with Kotlin and Java
* AI-powered mobile products with LLM integrations
* Firebase-based mobile apps and backend-connected features
* REST API integrations and data-driven app flows
* Subscription-based apps with IAP and monetization setup
* App Store and Google Play ready releases
* Analytics, attribution, push notifications, and growth tracking
* ASO-focused product pages, screenshots, metadata, and store optimization
* Clean, scalable mobile architecture for real product teams

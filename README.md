## 👋 About me

I’m **Nazar Kuzenko**, a **Senior Mobile Developer** focused on building practical, polished, and scalable mobile products.

My main stack is **Flutter, Dart, Kotlin, Firebase, REST APIs, subscriptions, analytics, and AI-powered app features**.

I build apps from idea to production: product structure, mobile architecture, clean UI, backend integration, analytics, monetization, and release preparation for **Google Play** and the **App Store**.

Currently building **Sych-Tech** — an independent mobile app studio focused on AI-powered apps, useful digital tools, and prompt-based workflows.

## 👋 About me

I’m **Nazar Kuzenko**, a **Senior / Lead Mobile Developer** with **5+ years of professional experience** and **7 years overall in mobile development**.

I build and release production mobile apps for **Android and iOS**, with a strong focus on **Flutter, Dart, Kotlin, Java, Firebase, REST APIs, subscriptions, analytics, AI integrations, App Store Connect, and Google Play Console**.

My experience covers the full product cycle: idea validation, feature planning, mobile architecture, UI implementation, backend integration, Firebase setup, analytics events, in-app purchases, testing, release preparation, store optimization, and post-release iteration.

Currently building **Sych-Tech** — an independent mobile app studio focused on AI-powered consumer apps, mobile-first products, and practical AI workflows.

## 🚀 What I build

* Production-ready Flutter mobile apps
* Native Android apps with Kotlin and Java
* AI-powered mobile products with LLM integrations
* Firebase-based mobile apps and backend-connected features
* REST API integrations and data-driven app flows
* Subscription-based apps with IAP and monetization setup
* App Store and Google Play ready releases
